# Sicherheit

CalShadow verarbeitet Zugangsdaten zu zwei Kalendern und schreibt in einen beruflichen Kalender.
Sicherheitslücken bitte **nicht** als öffentliches Issue melden, sondern vertraulich über
[GitHub Security Advisories](https://github.com/Antrilas/calshadow/security/advisories/new)
(„Report a vulnerability“).

Hilfreich sind eine Beschreibung, betroffene Version und – falls möglich – Schritte zum Nachstellen.
Ich melde mich so bald wie möglich zurück.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils neueste veröffentlichte Version.
